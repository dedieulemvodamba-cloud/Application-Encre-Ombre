📁 Etape 1 — Structure des fichiers

Voici les fichiers configurés dans votre projet Encre & Ombre :

STRUCTURE DU PROJET 
📂 encre-et-ombre/
├── 📄 index.html               ← Entrée principale avec balises PWA
├── 📄 public/manifest.json     ← Manifeste Web App officiel
├── 📄 public/sw.js             ← Service Worker avec cache 24h
├── 📄 public/guide-hors-ligne.html ← Ce guide interactif

🔧 Etape 2 — Code présent dans le HTML

Les balises suivantes sont insérées dans le <head> de votre site :

CODE PWA INTÉGRÉ 
<!-- PWA Manifest & Theme -->
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#c9a84c">

<!-- Support iPhone / iPad (iOS Safari) -->
<meta name="mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="Encre & Ombre">
<link rel="apple-touch-icon" href="/icon-192.png">

Le Service Worker est enregistré automatiquement dès le chargement de la page :

ACTIVATION AUTOMATIQUE 
<script>
if ('serviceWorker' in navigator) {
  window.addEventListener('load', function() {
    navigator.serviceWorker
      .register('/sw.js')
      .then(function(reg) {
        console.log('✅ Mode hors-ligne actif !', reg.scope);
      })
      .catch(function(err) {
        console.log('Erreur SW:', err);
      });
  });
}
</script>
✅ Ce code active automatiquement le mode hors-ligne. Après votre première visite en ligne, le site fonctionne pendant 24 heures sans connexion internet.

⏱️ Etape 4 — Fonctionnement du cache 24 heures

CYCLE DE VIE DU CACHE 
Première visite (avec internet) :
  → Le navigateur télécharge tous les fichiers et polices
  → Le Service Worker les sauvegarde en cache local
  → Durée de validité programmée : 24 heures (86 400 000 ms)

Visites suivantes (sans internet / hors-ligne) :
  → Le navigateur utilise le cache local instantané
  → Le site et la bibliothèque s'ouvrent sans connexion
  → Dès le retour d'une connexion internet, le cache se rafraîchit automatiquement

Fichiers mis en cache :
  ✅ Application React & catalogue complet
  ✅ Polices Google Fonts (Playfair Display, Plus Jakarta Sans)
  ✅ Images, logos et icônes
  ✅ Styles CSS & scripts JS

📲 Etape 5 — Installer comme une vraie application

Grâce au manifest.json, vous et vos lecteurs pouvez installer Encre & Ombre comme une vraie application mobile :

ANDROID (Chrome, Edge, Samsung Internet) 
1. Ouvrez le site dans Chrome
2. Appuyez sur les 3 points verticaux en haut à droite
3. Sélectionnez "Installer l'application" ou "Ajouter à l'écran d'accueil"
4. Confirmez l'installation
→ L'icône Encre & Ombre apparaît sur votre écran d'accueil comme une application native !
iOS (iPhone & iPad Safari) 
1. Ouvrez le site dans Safari
2. Appuyez sur l'icône Partager (le carré avec la flèche vers le haut)
3. Faites défiler et sélectionnez "Sur l'écran d'accueil"
4. Confirmez en appuyant sur "Ajouter"
→ L'application Encre & Ombre s'ouvre en plein écran sans barre Safari !
